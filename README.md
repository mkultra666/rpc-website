# Rave Parties Corp — demo local

Sitio estático y autocontenido. No necesita instalar paquetes ni conectarse a un backend.

## Abrir

Ejecutá `abrir-rpc.bat` o abrí `index.html` con un navegador moderno.

La compra es una demostración: valida los datos, genera una entrada y la guarda sólo en `localStorage` del navegador. No procesa pagos ni envía información. Los únicos enlaces externos son los accesos oficiales a Instagram, YouTube, SoundCloud, Linktree y WhatsApp.
